# Travel Guide Builder

一个结构化的 5 步旅行攻略工作流,把"帮我做攻略"从模糊的聊天变成有约束的产出流程。可以用于任何 LLM agent。

## 它做什么

不只是列景点。一份完整的攻略需要回答 5 件事:

- 你的硬约束是什么(到达离开时间、要赶的飞机/火车)?
- 哪些景点可以选?它们在地图上怎么分布?
- 选好的景点怎么顺路排?
- 排成时间表后,哪些时段是脆弱的?
- 出发前要订什么?

这套工作流强制走完这 5 步,不许跳过。

## 适合什么场景

- 多日多城市行程(高铁/KTX 跨城、机场往返)
- 时间紧的旅行(下午到、第二天傍晚走)
- 想要"行程能不能跑下来"的诚实评估,而不是"看起来很美但漏洞百出"的清单

## 不适合什么场景

- 单一事实问题("卢浮宫几点开门?")
- 没有规划成分的纯推荐("东京有什么好吃的?")
- 签证/保险等行政问题

## 两个版本

- `SKILL.md` — 英文版,规则更精确,模型遵守度高
- `SKILL.zh-CN.md` — 中文版,中文用户读起来更顺

两个版本规则等价。任选其一加载即可,**不要同时加载两份**——会触发歧义。

## 怎么用

把对应版本的文件作为 system prompt / instruction 注入你的 agent,然后问"帮我规划去 X 的旅行",这套流程就会触发。

不同 agent 的具体加载方式不同——查对应平台的文档即可。
